# Desktop capture (archived spike)

This Electron app is an **optional desktop-capture spike**. It is **not** part of
the assessor Docker path and is not required to demonstrate the web app, Chrome
extension, API, walkthrough overlay, or analytics flows.

For the submission demo, use:

- `apps/web` + `apps/api` via `docker compose`
- `apps/extension` (load `apps/extension/dist`)

Do not treat packaging or running `apps/desktop` as a Completeness requirement
for the Compose assessor path.
